**TITLE:**
"Number Series — 8 Patterns That Appear Every Exam" 🔢 ✏️

**SECTIONS (each as a hand-drawn labeled box with examples):**

1. **Arithmetic Series** (add/subtract same number)
   - 3, 7, 11, 15, 19 → +4 each time
   - 50, 43, 36, 29 → −7 each time

2. **Geometric Series** (multiply/divide same number)
   - 2, 6, 18, 54, 162 → ×3
   - 512, 256, 128, 64 → ÷2

3. **Squares Series**
   - 1, 4, 9, 16, 25, 36 → n²
   - 2, 5, 10, 17, 26, 37 → n²+1

4. **Cubes Series**
   - 1, 8, 27, 64, 125 → n³
   - 2, 9, 28, 65, 126 → n³+1

5. **Fibonacci / Sum of Previous Two**
   - 1, 1, 2, 3, 5, 8, 13, 21 → each = sum of previous 2
   - 2, 4, 6, 10, 16, 26 → same rule, different start

6. **Alternating Series** (two interlaced series)
   - 2, 5, 4, 10, 6, 15, 8 → even positions: ×2 of position, odd: ×5
   - Tip: check odd and even positions separately!

7. **Difference Series** (differences form a pattern)
   - 1, 2, 4, 7, 11, 16, 22 → differences are 1,2,3,4,5,6
   - 3, 6, 11, 18, 27 → differences are 3,5,7,9 (odd numbers)

8. **Mixed / Product + Addition**
   - 1, 2, 6, 24, 120 → ×2, ×3, ×4, ×5 (factorials)
   - 1, 3, 7, 15, 31 → ×2+1 each time

**Bottom strip (yellow):**
"HOW TO CRACK: Step 1 → Check differences. Step 2 → Check ratios. Step 3 → Check if positions match n², n³. Step 4 → Split into odd/even terms."
