**6 SECTIONS:**

**1. Letter Shift Coding** (blue border)
- "If DEAR = GHDU, then FACE = ?"
- +3 shift: D→G, E→H, A→D, R→U
- Answer: IDFH
- Tip: Count forward/backward in alphabet, check if shift is constant

**2. Position Value Coding** (green border)
- "A=1, B=2... Z=26 then BACK = ?"
- B=2, A=1, C=3, K=11 → CODE = 2+1+3+11 = 17
- Tip: Memorise A=1 to Z=26 or reverse Z=1

**3. Reverse Alphabet** (orange border)
- "Opposite letter: A↔Z, B↔Y, C↔X..."
- If BIG = YTR then COLD = ?
- B=Y, I=R, G=T → XLOW
- Tip: Opposite of n = 27−n

**4. Symbol/Number Replacement** (purple border)
- "CAT = 3120 then DOG = ?"
- C=3, A=1, T=20 (position values)
- D=4, O=15, G=7 → DOG = 41507

**5. Word/Letter Rearrangement** (red border)
- "SMART is coded as TRAMS, then SHARP = ?"
- SMART reversed = TRAMS ✓
- SHARP reversed = PRAHS
- Tip: Try reverse, mirror, swap first/last

**6. Mixed Operation Coding** (teal border)
- "4×3+2 if ABCD=4326, find BC"
- Each letter maps to a digit: A=4, B=3, C=2, D=6
- BC = 32
- Tip: Set up the mapping table first, then decode
