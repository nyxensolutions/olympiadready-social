**SECTION 1 (top left) — "Basic Ratio Rules":**
- a:b = a/b (always simplify using HCF)
- a:b:c — three-way ratio
- "If A:B = 3:4 and B:C = 5:6, find A:B:C"
  → Make B common: A:B = 15:20, B:C = 20:24
  → A:B:C = 15:20:24
- Key: multiply to make middle term equal

**SECTION 2 (top right) — "Direct & Inverse Proportion":**
Direct Proportion (more → more):
- y = kx (as x increases, y increases)
- x₁/y₁ = x₂/y₂
- Example: 5 workers make 50 items, how many do 8 workers make?
  → 50/5 = y/8 → y = 80

Inverse Proportion (more → less):
- xy = constant
- x₁y₁ = x₂y₂
- Example: 4 workers take 12 days, how long for 6 workers?
  → 4×12 = 6×d → d = 8 days

**SECTION 3 (bottom left) — "Ratio Division (Sharing)":**
- "Divide 720 in ratio 3:4:5"
  → Total parts = 12 → Each part = 60
  → 3×60:4×60:5×60 = 180:240:300 ✓
- "A:B = 2:3, B:C = 4:5. A gets ₹400 less than C. Find total"
  → Make B common: A:B:C = 8:12:15
  → C−A = 7 parts = 400 → 1 part = 400/7
  → Total = 35 parts = ₹2000

**SECTION 4 (bottom right) — "Mixture & Allegation":**
Allegation cross-rule for mixing two items at different values:
```
   Cheaper   Dearer
      c         d
         \   /
          \ /
          Mean M
          / \
         /   \
      (d-M)  (M-c)
```
→ Ratio of cheaper:dearer = (d−M):(M−c)
- Example: ₹40/kg and ₹60/kg mixed to get ₹50/kg
  → Ratio = (60−50):(50−40) = 10:10 = 1:1
